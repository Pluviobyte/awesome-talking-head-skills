# Awesome Talking Head Skills

收集表现好的口播（talking head）博主，把他们出镜的肢体动作、表情、机位和开头结构拆成可复用的 Agent Skill。

适用场景：用 Agent 加视频模型做口播数字人时，告诉模型“这个人该怎么动”，让数字人的动作有固定词汇、固定范围、踩在台词重音上，减少乱比划和崩手。

> 状态：建设中。

## 收录原则

- 只提炼动作节奏和结构，不收录博主的原视频、原画面、长相或完整逐字稿
- 每条样本只记录公开链接和基本数据，原片请到原平台观看
- 生成数字人时，Skill 里的文字描述给 Agent 用，不要把原视频当参考视频喂给生成模型
- 参考图只用自己或已获授权的形象；发布时按平台要求标注 AI 生成内容
